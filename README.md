# Sprint_6

## Список реализованных тестов

### ❓ Раздел «Вопросы о важном» (`TestMainPage`)
Класс тестов, проверяющий работу выпадающего списка с вопросами и ответами.

| Тест | Описание |
|:---|:---|
| `test_question_and_answer` | **Параметризованный тест (8 кейсов):** Проверяет, что при клике на стрелочку каждого вопроса раскрывается соответствующий ответ. Скроллит до блока вопросов, кликает на вопрос по индексу и сверяет текст ответа с ожидаемым из тестовых данных. |

### 🛵 Заказ самоката (`TestOrderPage`)
Класс тестов, проверяющий полный флоу оформления заказа.

| Тест | Описание |
|:---|:---|
| `test_create_order` | **Параметризованный End-to-End сценарий (2 набора данных):** Проверяет полный цикл оформления заказа через две точки входа — кнопка «Заказать» вверху и внизу страницы. Включает заполнение двух страниц формы и проверку появления модального окна об успешном создании заказа. |

### 🔁 Редиректы по логотипам (`TestLogoRedirect`)
Класс тестов, проверяющий навигацию через логотипы в шапке сайта.

| Тест | Описание |
|:---|:---|
| `test_logoredirect_to_yandex_success` | **Проверка редиректа:** Клик на логотип Яндекса открывает в новой вкладке главную страницу Яндекса. |
| `test_logoredirect_to_scooter_main_page_success` | **Проверка навигации:** Клик на логотип Самоката возвращает пользователя на главную страницу сервиса. |

## 🛠 Технические особенности реализации

* **Page Object Model:** Каждая страница описана в отдельном классе в пакете `pages`. Локаторы вынесены в отдельный пакет `locators`.
* **Параметризация:** Используется в тестах FAQ (8 индексов вопросов) и в тестах заказа (2 набора пользовательских данных с разными точками входа).
* **Динамические ожидания:** Вместо нестабильных `time.sleep` используются `Explicit Waits`:
  * `EC.visibility_of_element_located`: ожидание появления элемента на странице.
  * `EC.element_to_be_clickable`: ожидание готовности элемента к клику.
  * `EC.number_of_windows_to_be`: ожидание открытия новой вкладки.
  * `EC.url_contains`: ожидание редиректа на целевой URL.
* **Allure-отчёт:** Все тесты размечены декораторами `@allure.suite`, `@allure.title`, `@allure.description` и `@allure.step` для генерации читаемого отчёта.

## 🚀 Запуск проекта

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск тестов
```bash
pytest
```

### Генерация Allure-отчёта
```bash
allure serve allure-results
```
